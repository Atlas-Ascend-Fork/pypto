# 产品型号和芯片标签规范

适用范围：`docs/` 下所有涉及产品型号表述的文档（API 文档、功能指南、README 等）。

规则编号范围：`PRD-01~12`。

本文件分两部分：**规则**（写作时遵守）与**检查方法**（排查验证手段）。

## 规则

### 产品型号标准名称（PRD-01~02）

| 编号 | 规则 | 严重级别 |
|------|------|---------|
| PRD-01 | 产品名称只用以下十种标准写法（逐字符一致，含后缀）。<br>Ascend/Atlas 三款（必列）：<br>`Ascend 950PR&950DT系列产品`<br>`Atlas A3系列产品`<br>`Atlas A2系列产品`<br>Kirin 七款（可选列入）：<br>`KirinX90处理器系列产品`<br>`Kirin9020处理器系列产品`<br>`Kirin9030处理器系列产品`<br>`Kirin9050处理器系列产品`<br>`KirinDev0001处理器系列产品`<br>`KirinDev0002处理器系列产品`<br>`KirinDev0003处理器系列产品` | HIGH |
| PRD-02 | 禁止变体写法：`Ascend 950`、`950PR系列`、`Ascend 950PR`、`Atlas A3系列`、`A2系列产品`、`Ascend950`（无空格）、`950PR & 950DT`（&两侧加空格）等 | HIGH |

### npu 芯片标签（PRD-03~08）

PyPTO 文档通过 HTML 注释标签实现**按芯片过滤发布**：发布时仅保留目标芯片标签块内的内容与未打标内容。语法：

```html
<!-- npu="950" id1 -->
- Ascend 950PR&950DT系列产品：支持
<!-- end id1 -->
```

| 编号 | 规则 | 严重级别 |
|------|------|---------|
| PRD-03 | 标签值为以下十种之一，或其中多个以英文逗号组合（如 `npu="x90,9030"`，块内容对所列全部芯片生效）：`950`、`A3`、`910b`（小写b）、`x90`（小写x）、`9020`、`9030`、`9050`、`kirin1`、`kirin2`、`kirin3`（小写）；不得出现其他值（如 910B、a3、Ascend950、X90、Kirin1、kirin0001） | HIGH |
| PRD-04 | 起始标签`<!-- npu="950" id2 -->`与结束标签`<!-- end id2 -->`必须成对出现，**id 在单个文件内唯一**，建议从 1 递增编号 | CRITICAL |
| PRD-05 | Ascend/Atlas 三款标签块**尽量按由新到旧**顺序排列：`950` → `A3` → `910b`，与"产品支持情况"各行顺序一致（未列入的型号跳过）；Kirin 系列标签（`x90`/`9020`/`9030`/`9050`/`kirin1`/`kirin2`/`kirin3`）无顺序要求；多值标签按首个值参与顺序核对 | MEDIUM |
| PRD-06 | 标签值与产品名严格对应：<br>`950`↔`Ascend 950PR&950DT系列产品`<br>`A3`↔`Atlas A3系列产品`<br>`910b`↔`Atlas A2系列产品`<br>`x90`↔`KirinX90处理器系列产品`<br>`9020`↔`Kirin9020处理器系列产品`<br>`9030`↔`Kirin9030处理器系列产品`<br>`9050`↔`Kirin9050处理器系列产品`<br>`kirin1`↔`KirinDev0001处理器系列产品`<br>`kirin2`↔`KirinDev0002处理器系列产品`<br>`kirin3`↔`KirinDev0003处理器系列产品`<br>同一内容块中标签值与行内产品名不得错配；多值标签表示块内容对所列全部芯片生效，无须逐一对应产品名行 | CRITICAL |
| PRD-07 | 标签不得交叉嵌套（`<!-- npu="950" id3 --> ... <!-- npu="A3" id4 --> ... <!-- end id3 --> ... <!-- end id4 -->` 为错误） | CRITICAL |
| PRD-08 | 同一处的各型号内容若完全相同，无须用标签包裹，直接写一份即可；仅差异部分用标签区分 | LOW |

### 产品差异表述（PRD-09~12）

当不同型号存在功能差异时，**文字说明与芯片标签缺一不可**：差异须用文字明确写出，且必须用 npu 芯片标签包裹。标签的作用是支持按芯片过滤发布文档，须确保**筛选任何一款芯片时，都能发布出该芯片的完整相关内容，且不包含其他芯片内容**。

| 编号 | 规则 | 严重级别 |
|------|------|---------|
| PRD-09 | 型号间功能差异（数据类型、格式、约束）统一归入"约束说明"章节，不散落在"功能说明"或"参数说明"正文；API 文档的展开细则与参数说明跳转引导见 rules-api.md（API-18、API-23） | HIGH |
| PRD-10 | "产品支持情况"是接口级结论：某型号**接口整体**不可用时须为"不支持"；仅**特性级**受限（数据类型、格式、参数等）时保持"支持"，差异统一在"约束说明"以 npu 标签展开。两章不得自相矛盾，变更任一侧时须同步核对另一侧 | HIGH |
| PRD-11 | 型号间功能差异内容必须全部包裹在对应芯片的 npu 标签块内，不得裸露在无标签正文中——裸露内容会发布到所有芯片视角，导致筛选其他芯片时混入无关内容 | CRITICAL |
| PRD-12 | 型号差异采用"通用 + 差异"表述：各芯片一致的通用能力直接写正文、不打标；仅部分芯片存在差异时，**只为存在差异的芯片写标签块，不要求全部芯片罗列**。筛选任一芯片时，其视角 = 通用正文 + 本芯片差异块，组合后语义须正确完整 | MEDIUM |

## 检查方法

### 产品名称变体排查（PRD-01~02）

```bash
# 提取所有产品型号表述并统计变体
grep -rnoE 'Ascend[^：:，。\n<]*|Atlas[^：:，。\n<]*|Kirin[^：:，。\n<]*' docs/zh --include='*.md' | grep -vE 'Ascend 950PR&950DT系列产品|Atlas A3系列产品|Atlas A2系列产品|KirinX90处理器系列产品|Kirin9020处理器系列产品|Kirin9030处理器系列产品|Kirin9050处理器系列产品|KirinDev0001处理器系列产品|KirinDev0002处理器系列产品|KirinDev0003处理器系列产品'
# 输出非空即存在非标准写法（需人工确认是否为型号表述）
```

### 标签语法检查（PRD-03~08）

```bash
# 1. 校验标签值合法（单个值或逗号分隔多值，多值须为合法值的组合）
grep -rnoE 'npu="[^"]*"' <目标文件> | grep -vE 'npu="(950|A3|910b|x90|9020|9030|9050|kirin1|kirin2|kirin3)(,(950|A3|910b|x90|9020|9030|9050|kirin1|kirin2|kirin3))*"'

# 2. 校验 start/end 配对与 id 唯一性（对单个文件）
grep -oE 'npu="[^"]*" id[0-9]+|end id[0-9]+' <目标文件>
# 人工核对：每个 idN 恰好出现一次 start、一次 end，且 start 在 end 之前

# 3. 校验标签顺序
grep -oE 'npu="[^"]*"' <目标文件>
# Ascend/Atlas 三款应呈 950/A3/910b 顺序（由新到旧）；Kirin 标签无顺序要求（多值标签按首个值核对）
```

### 按芯片过滤模拟检查（PRD-11、PRD-12）

过滤不变量验证，对每个 chip ∈ {950, A3, 910b, x90, 9020, 9030, 9050, kirin1, kirin2, kirin3} 执行：

```bash
# 模拟筛选某芯片后的发布内容（注意：标签可能带缩进，匹配不锚定行首；支持逗号分隔多值标签）
awk -v chip='<芯片>' '
/<!-- npu=/ { match($0, /npu="[^"]*"/); vals = substr($0, RSTART+5, RLENGTH-6); keep = (index("," vals ",", "," chip ",") > 0); if (keep) print; inblock=1; next }
/<!-- end/ { if (keep) print; inblock=0; keep=0; next }
{ if (!inblock || keep) print }
' <目标文件>
```

对过滤结果检查两点：

1. **不包含其他芯片内容**：过滤结果中不得出现其他产品名的差异行（如 950 视角不得出现"Atlas A3系列产品：DT_..."）——出现即说明该差异行未打标（PRD-11）或标签值写错（PRD-03）
2. **内容完整**：通用正文 + 本芯片差异块的组合须覆盖本芯片的全部差异信息——若本芯片特有的差异只出现在其他芯片的标签块中（或完全缺失），即为违规（PRD-12）
