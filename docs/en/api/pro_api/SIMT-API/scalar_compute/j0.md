## Description

Computes the zeroth-order Bessel function of the first kind.

$$result = J_0(value)$$

This function is an even function, which means $J_0(-value)=J_0(value)$.

## Prototype

```python
pypto_pro.language.simt.j0(
    value: Scalar,
) -> Scalar
```

## Parameters

| Parameter| Input/Output| Description|
|---|---|---|
| value | Input| Source operand of the scalar type. Only DT_FP32 is supported. The tensor or tile element needs to be accessed by subscript before being passed.|

## Constraints

This API can only be called in the SIMT kernel, SIMT vector function, or SIMT helper.

## Return Value

Returns the zeroth-order Bessel function value of the first kind. The data type is DT_FP32.

| value| Return Value|
|---|---|
| ±Inf | +0 |
| NaN | NaN |

## Examples

```python
import pypto_pro.language as pl


@pl.vector_function(mode="simt", max_threads=64)
def j0_example(
    value: pl.Tensor[[1, 64], pl.DT_FP32],
    output: pl.Tensor[[1, 64], pl.DT_FP32],
):
    tid = pl.simt.linear_thread_idx()
    output[0, tid] = pl.simt.j0(value[0, tid])


@pl.jit()
def j0_kernel(
    value: pl.Tensor[[1, 64], pl.DT_FP32],
    output: pl.Tensor[[1, 64], pl.DT_FP32],
):
    with pl.section_vector():
        j0_example[64](value, output)
```
