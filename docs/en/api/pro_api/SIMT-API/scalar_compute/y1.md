## Description

Computes the first-order Bessel function of the second kind.

$$result = Y_1(value)$$

## Prototype

```python
pypto_pro.language.simt.y1(
    value: Scalar,
) -> Scalar
```

## Parameters

| Parameter| Input/Output| Description|
|---|---|---|
| value | Input| Source operand, which is of the scalar type. The value is a positive real number within the domain of real numbers. Only DT_FP32 is supported. The tensor or tile element needs to be accessed by subscript before being passed.|

## Constraints

This API can only be called in the SIMT kernel, SIMT vector function, or SIMT helper.

## Return Value

Returns the value of the first-order Bessel function of the second kind. The data type is DT_FP32.

| value| Return Value|
|---|---|
| ±0 | -Inf |
| Finite negative number or -Inf| NaN |
| +Inf | +0 |
| NaN | NaN |

## Examples

```python
import pypto_pro.language as pl


@pl.vector_function(mode="simt", max_threads=64)
def y1_example(
    value: pl.Tensor[[1, 64], pl.DT_FP32],
    output: pl.Tensor[[1, 64], pl.DT_FP32],
):
    tid = pl.simt.linear_thread_idx()
    output[0, tid] = pl.simt.y1(value[0, tid])


@pl.jit()
def y1_kernel(
    value: pl.Tensor[[1, 64], pl.DT_FP32],
    output: pl.Tensor[[1, 64], pl.DT_FP32],
):
    with pl.section_vector():
        y1_example[64](value, output)
```
