## Description

IndexOrder defines the direction of the index sequence generated by [vf.arange](../sorting_and_indexing/arange.md). It controls whether the sequence is ascending or descending.

## Prototype

```python
class IndexOrder(enum.Enum):
     INCREASE_ORDER = ...  # Ascending sequence: dst[i] = start + i (default).
     DECREASE_ORDER = ...  # Descending sequence: dst[i] = start – i.
```

## Examples

```python
import pypto_pro.language as pl

@pl.vector_function
def vf_kernel():
    dst = vf.arange(0, dtype=pl.DT_INT32, index_order=pl.IndexOrder.INCREASE_ORDER)
```
