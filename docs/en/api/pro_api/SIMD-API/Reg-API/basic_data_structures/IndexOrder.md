## Description

IndexOrder defines the direction of the index sequence generated by [vf.arange](../sorting_and_indexing/arange.md), controlling whether the sequence is increasing or decreasing.

## Prototype

```python
class IndexOrder(enum.Enum):
     INCREASE_ORDER = ...  # Increasing sequence: dst[i] = start + i (default).
     DECREASE_ORDER = ...  # Decreasing sequence: dst[i] = start - i.
```

## Examples

```python
import pypto_pro.language as pl

@pl.vector_function
def vf_kernel():
    dst = vf.arange(start=0, order=pl.IndexOrder.INCREASE_ORDER)
```
