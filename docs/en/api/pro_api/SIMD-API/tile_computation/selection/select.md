## Description

Selects data element by element based on a mask. When the mask is true, the value from lhs is selected; when the mask is false, the value from rhs is selected. rhs can be a Tile or a Scalar. This API is typically used together with pypto_pro.language.eq, ne, lt, le, gt, and ge.

## Prototype

```python
pypto_pro.language.select(
    out: Tile,
    mask: Tile,
    lhs: Tile,
    rhs: Union[Tile, Scalar],
    tmp: Tile,
) -> None
```

## Parameters

| Parameter | Input/Output | Description |
|---|---|---|
| out | Output | Destination operand of the Tile type, stored in UB, whose shape must be the same as that of the input data Tile. Both Tile-Tile and Tile-Scalar modes support 8-, 16-, 32-, and 64-bit integers, DT_FP16, DT_BF16, and DT_FP32. |
| mask | Input | Source operand (mask) of the Tile type, stored in UB, in bit-packed format. The data type of the mask Tile is not restricted; DT_UINT8 is typically used, and the mask must be generated by a comparison API. |
| lhs | Input | Source operand (the data selected when the mask is true) of the Tile type, stored in UB, whose data type and shape must be the same as those of out. |
| rhs | Input | Source operand (the data selected when the mask is false) of the Tile or Scalar type, or a Python int or float constant that can be converted to a Scalar. When a Tile is passed, it is stored in UB, and its data type and shape must be the same as those of out. When a Scalar or a Python constant is passed, its data type must be compatible with the element type of out. |
| tmp | Input | Compatibility parameter of the Tile type. |

## Constraints

- out, mask, lhs, and rhs of the Tile type must be located in UB. out, lhs, and rhs of the Tile type must use row-major layout.
- out, lhs, and rhs of the Tile type must have the same shape, valid shape, and data type.

## Return Value

None

## Examples

### Select Between Two Tiles Based on Comparison Results

```python
import pypto_pro.language as pl


@pl.jit(auto_mutex=True)
def scalar_gt_select_kernel(
    a: pl.Tensor[[64, 128], pl.DT_FP32],
    b: pl.Tensor[[64, 128], pl.DT_FP32],
    mask_in: pl.Tensor[[64, 128], pl.DT_FP16],
    out: pl.Tensor[[64, 128], pl.DT_FP32],
):
    tt32 = pl.TileType(shape=[64, 128], dtype=pl.DT_FP32, target_memory=pl.MemorySpace.Vec)
    tile_a_group = pl.make_tile_group(type=tt32, addrs=0x0000, mutex_ids=[0])
    tile_b_group = pl.make_tile_group(type=tt32, addrs=0x8000, mutex_ids=[1])
    tile_out_group = pl.make_tile_group(type=tt32, addrs=0x10000, mutex_ids=[2])
    tmp_vec_group = pl.make_tile_group(type=tt32, addrs=0x18000, mutex_ids=[3])
    mask_fp16_group = pl.make_tile_group(
        type=pl.TileType(shape=[64, 128], dtype=pl.DT_FP16, target_memory=pl.MemorySpace.Vec),
        addrs=0x20000, mutex_ids=[4])
    mask_vec_group = pl.make_tile_group(
        type=pl.TileType(shape=[64, 128], dtype=pl.DT_UINT8, target_memory=pl.MemorySpace.Vec),
        addrs=0x24000, mutex_ids=[5])
    with pl.section_vector():
        tile_a = tile_a_group.current()
        tile_b = tile_b_group.current()
        tile_out = tile_out_group.current()
        tmp_vec = tmp_vec_group.current()
        mask_fp16 = mask_fp16_group.current()
        mask_vec = mask_vec_group.current()
        pl.load(tile_a, a, [0, 0])
        pl.load(tile_b, b, [0, 0])
        pl.load(mask_fp16, mask_in, [0, 0])
        # mask_fp16 > 0, generate the bitwise-compressed mask mask_vec.
        pl.gt(mask_vec, mask_fp16, 0.0)
        # Take lhs(=a) when the predicate is true; otherwise, take rhs(=b).
        pl.select(tile_out, mask_vec, tile_a, tile_b, tmp_vec)
        pl.store(out, tile_out, [0, 0])
```
