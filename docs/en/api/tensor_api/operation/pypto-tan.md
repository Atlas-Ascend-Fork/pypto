## Description

Computes the tangent (trigonometric function tan) of each element in the input tensor, performing element-wise operations.

$$
y_i = \tan(x_i)
$$

## Prototype

```python
tan(input: Tensor) -> Tensor
```

## Parameters

| Parameter| Input/Output| Description|
|--------|-----------|------|
| input  | Input     | Source operand.<br>Supported type: Tensor.<br>Supported data types of a tensor: DT_FP32, DT_FP16, and DT_BF16.<br>Empty tensors are not supported. The shape supports only 1 to 4 dimensions. The shape size must not exceed 2147483647 (INT32_MAX).|

## Return Value

Returns a tensor. Its shape and data type are the same as those of the input tensor, and its elements are the tangent values of the corresponding elements of the input tensor.

## Constraints

1. The input and output tensors must have the same type.
2. Tensor inputs do not support the `TileOpFormat.TILEOP_NZ` format.

## Examples

### TileShape Setting Example

Note: Before calling this operation API, set TileShape through set_vec_tile_shapes.

TileShape must have the same dimensions as the output.

Example 1: If the input shape is [m, n], the output is [m, n], and TileShape is set to [m1, n1], then m1 and n1 are used to tile the m and n axes, respectively.

```python
pypto.set_vec_tile_shapes(4, 16)
```

### API Call Example

```python
x = pypto.tensor([4], pypto.DT_FP32)
y = pypto.tan(x)
```

Result example:

```python
Input data x: [0.0000, 0.7854, 1.0472, -0.7854]
Output data y: [0.0000, 1.0000, 1.7321, -1.0000]
```
