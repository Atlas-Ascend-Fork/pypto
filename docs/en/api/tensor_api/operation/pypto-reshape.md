## Description

Changes the shape of a tensor, altering the shape of the **valid\_shape** portion.

## Precautions

- **Static shape supports `-1`**: When all axes of the tensor are static dimensions, the shape parameter supports using `-1` to automatically infer one dimension.
- **Dynamic shape does not support `-1`**: When any axis of the tensor is marked as `pypto.DYNAMIC`, the shape parameter cannot use `-1`; all dimension values must be explicitly specified. The dimension obtained from the dynamic axis `tensor.shape` is of the SymbolicScalar type and can be used in the shape parameter of reshape.
- **The input validshape is not automatically inherited**: If the input tensor carries a validshape and you want the output to also retain the validshape, you must compute the output validshape yourself and pass it through the `valid_shape` parameter. If it is not passed, reshape does not automatically infer the output validshape from the input validshape.
- **Recommended use of the inplace parameter**: When the constraints of inplace are satisfied, setting `inplace=True` can avoid additional data movement.

## Prototype

```python
reshape(input: Tensor,shape: List[int],*,valid_shape: Optional[List[Union[int, SymbolicScalar]]] = None, inplace: bool = False) -> Tensor
```

## Parameters

| Parameter | Input/Output | Description |
|-------------|-----------|----------------------------------------------------------------------|
| input       | Input      | Source operand.<br>Supported data types: data types supported by PyPTO.<br>Empty tensors are not supported. |
| shape       | Input      | Target shape.<br>- **Static shape**: Supports using `-1` to automatically infer one dimension.<br>- **Dynamic shape**: Does not support `-1`; all dimension values must be explicitly specified. A dimension value can be a concrete integer or a SymbolicScalar (obtained from a dynamic axis). |
| valid_shape | Input      | Shape of the valid data in the output tensor.<br>When the input carries a validshape, the framework does not automatically infer the output validshape. If the output needs to retain the validshape, you must compute it and pass it through this parameter. |
| inplace     | Input      | Whether to perform the operation inplace, defaulting to **False**. When set to **True**, no new address is allocated for the output. |

## Return Value

Returns the output tensor. The data type of the tensor is the same as that of input, and its shape is the shape specified by the input parameter.

## Constraints

1. When reshape is performed on a tensor generated by view, only inplace=False is allowed.
2. When inplace is True, reshape usually needs to be placed alone in loop (1). When there are no other types of operations alongside it, loop (1) can be omitted and the framework automatically completes it, as shown in Example 2.
3. The output of inplace=True cannot be used as the final output of the function.
4. **inplace** set to **False** applies only to static shapes; **inplace** set to **True** is compatible with both static and dynamic shapes.

## Examples

Example 1:

```python
x = pypto.tensor([2, 2], pypto.DT_FP32)
y = pypto.reshape(x, [4, 1], [2, 1])
z = pypto.add(y, 1.0)
```

The results are as follows:

```python
Input data x: [[1, 2],
            [3, 4]]
Output data y: [[1],
            [2],
            [3],
            [4]]
Output data z: [[2],
            [3],
            [4],
            [5]]
```

Example 2:

```python
x = pypto.tensor([2, 2], pypto.DT_FP32)
# reshape(..., inplace=True) is used alone inside loop(1). loop(1) can be omitted.
for _ in pypto.loop(1, name="reshape_inplace", idx_name="tmp_loop"):
    x_1 = x.reshape([4], inplace=True)
for _ in pypto.loop(1, name="loop", idx_name="loop"):
    y = pypto.add(x_1, 1.0)
```

The results are as follows:

```python
Input data x: [[1, 2],
            [3, 4]]
Output data y: [2, 3, 4, 5]
```
