## Description

Changes the tensor shape and the shape of the valid\_shape part.

## Precautions

- **Static shape supports `-1`**: When all axes of a tensor are static dimensions, the shape parameter supports using `-1` to automatically infer a dimension.
- **Dynamic shape does not support `-1`**: When an axis of a tensor is marked as `pypto.DYNAMIC`, the shape parameter cannot use `-1`. Instead, all dimension values must be explicitly specified. The dimension obtained from the dynamic axis `tensor.shape` is of the SymbolicScalar type and can be used in the shape parameter of reshape.
- **validshape is not automatically inherited**: If the input tensor has a valid shape and you want to retain the valid shape in the output, you must compute the valid shape of the output and pass it through `valid_shape`. If the parameter is not passed, reshape does not automatically infer the output valid shape based on the input valid shape.
- **Using the inplace parameter is recommended**: When the constraints of inplace are met, setting `inplace=True` can avoid extra data movement.

## Prototype

```python
reshape(input: Tensor,shape: List[int],*,valid_shape: Optional[List[Union[int, SymbolicScalar]]] = None, inplace: bool = False) -> Tensor
```

## Parameters

| Parameter     | Input/Output| Description                                                                |
|-------------|-----------|----------------------------------------------------------------------|
| input       | Input     | Source operand.<br>The supported data types are those supported by PyPTO. <!-- npu="x90,9030,9050" id9 -->For details about the supported data types of Kirin, see [Tensor Data Types](#constraints).<!-- end id9 --><br>Empty tensors are not supported.|
| shape       | Input     | Target shape.<br>- **Static shape**: `-1` can be used to automatically infer a dimension.<br>- **Dynamic shape**: `-1` is not supported. All dimension values must be explicitly specified. A dimension value can be a concrete integer or SymbolicScalar (obtained from the dynamic axis).|
| valid_shape | Input     | Shape of the valid data of the output tensor.<br>If the input contains validshape, the framework does not automatically infer the output validshape. If the output needs to retain the validshape, you must compute it and pass it through this parameter.|
| inplace     | Input     | Whether to perform the operation inplace, defaulting to False. If this parameter is set to True, no new address is allocated for the output.|

## Return Value

Returns the output tensor. Its data type is the same as that of input, and its shape is the shape specified by the input parameter.

## Constraints

1. When reshape is performed on a tensor generated by view, inplace can only be False.
2. When inplace is True, reshape usually needs to be placed alone in loop (1). When there are no other types of operations alongside it, loop (1) can be omitted and the framework automatically completes it, as shown in Example 2.
3. The output of inplace=True cannot be used as the final output of the function.
4. inplace=False applies only to static shapes. inplace=True applies to both static and dynamic shapes.

## Examples

Example 1:

```python
x = pypto.tensor([2, 2], pypto.DT_FP32)
y = pypto.reshape(x, [4, 1], [2, 1])
z = pypto.add(y, 1.0)
```

Result example:

```python
Input data x: [[1, 2],
            [3, 4]]
Output data y: [[1],
            [2],
            [3],
            [4]]
Output data z: [[2],
            [3],
            [4],
            [5]]
```

Example 2:

```python
x = pypto.tensor([2, 2], pypto.DT_FP32)
# reshape(..., inplace=True) is placed in loop(1) separately. loop(1) can be omitted.
for _ in pypto.loop(1, name="reshape_inplace", idx_name="tmp_loop"):
    x_1 = x.reshape([4], inplace=True)
for _ in pypto.loop(1, name="loop", idx_name="loop"):
    y = pypto.add(x_1, 1.0)
```

Result example:

```python
Input data x: [[1, 2],
            [3, 4]]
Output data y: [2, 3, 4, 5]
```
