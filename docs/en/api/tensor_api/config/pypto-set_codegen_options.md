## Description

Sets the options for codegen.

## Prototype

```python
set_codegen_options(*,
                    support_dynamic_aligned: bool = None,
                    enable_pmu_trace: bool = None) -> None
```

## Parameters

| Parameter                   | Input/Output | Description                                                                 |
|-----------------------------|--------------|------------------------------------------------------------------------------|
| support_dynamic_aligned     | Input        | Meaning: whether to support dynamic Shape. <br> Description: <br> When the value is True, the device-side binary generated by the operator supports the dynamic Shape aligned scenario. <br> When the value is False, the device-side binary generated by the operator supports only the dynamic Shape non-aligned scenario. <br> Type: bool <br> Value range: {True, False} <br> Default value: False (when the operator confirms dynamic Shape and all last axes of the Shape are aligned, you can try enabling this option to check whether there is a performance gain) <br> Affected Pass scope: None. It only affects the device-side target code generated by the CodeGen module. |
| enable_pmu_trace            | Input        | Meaning: whether to enable PMU Trace. <br> Description: <br> When the value is True, codegen inserts `bisheng::cce::mark_stamp` marks at the beginning and end of the CCE code corresponding to each leaf function, and assigns a PMU ID to each mark for locating the corresponding kernel in the in-core pipeline. At runtime, `msprof --instr-profiling=on` must be used for instruction-level collection. <br> When the value is False, no PMU marks are inserted. <br> Type: bool <br> Value range: {True, False} <br> Default value: False <br> Affected Pass scope: None. It only affects the device-side target code generated by the CodeGen module. |

## Return Value

**void**: The **Set** method has no return value. The setting takes effect immediately upon success.

## Constraints

The effect of the support_dynamic_aligned option will be optimized through the Pass inference mechanism in the future, so you do not need to set it manually. You are advised to use it with caution.

enable\_pmu\_trace Usage notes:

