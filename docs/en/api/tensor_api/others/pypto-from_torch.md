## Description

Converts torch.Tensor to pypto.Tensor. You can explicitly specify the name of the converted pypto.Tensor. You can mark a specified dimension of the converted pypto.Tensor as a dynamic dimension, indicating that the dimension can be changed in the subsequent build or runtime phase.

## Prototype

```python
from_torch(tensor: torch.Tensor, name: str="", *, dynamic_axis: Optional[List[int]] = None,
           tensor_format: Optional[TileOpFormat] = None, dtype: Optional[DataType] = None) -> pypto.Tensor
```

## Parameters

| Parameter        | Input/Output| Description                                                                |
|----------------|-----------|----------------------------------------------------------------------|
| tensor         | Input     | torch.Tensor object to be converted to pypto.Tensor.|
| name           | Input     | Name of the pypto.Tensor. The default value is an empty string, indicating that the name is automatically generated by from_torch.|
| dynamic_axis   | Input     | List of dimension indices to be marked as dynamic. The default value is None, indicating that no dimension is marked.|
| tensor_format  | Input     | pypto.TileOpFormat format to be specified. If this parameter is set to None, the format is automatically inferred based on the tensor NPU format.|
| dtype      | Input     | Type of the pypto.DataType to be specified. If it is None, the value is automatically inferred based on the dtype of torch.Tensor.|

## Return Value

Returns the converted pypto.Tensor.

## Constraints

- The input tensor must be of the torch.Tensor type or its subclass.
- The input tensor is contiguous in the specified memory format (tensor.is\_contiguous\(\) == True).
- The input tensor supports the following data types (dtype):
    - torch.float16
    - torch.bfloat16
    - torch.float32
    - torch.float64
    - torch.int8
    - torch.uint8
    - torch.int16
    - torch.uint16
    - torch.int32

## Examples

```python
x= torch.randn(2, 3)
x_pto = pypto.from_torch(x)
print(x_pto.shape)
y = torch.randn(2, 3)
y_pto = pypto.from_torch(y, "y", dynamic_axis=[0])
print(y_pto.shape)
z = torch.randn(2, 3)
z_pto = pypto.from_torch(z, "z", tensor_format=pypto.TileOpFormat.TILEOP_NZ)
print(z_pto.format)
k = torch.randn(2, 3)
k_pto = pypto.from_torch(k, "k", dtype=pypto.DataType.DT_HF8)
print(k_pto.dtype)
```
